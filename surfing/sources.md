- **International Life Saving Federation** (ilsf.org) did not respond to our checker, so it has no card; it's mentioned only through the ISA/ILS course described on ISA's page.
- SFI's list of accredited schools (2024 list page) returned 404, so we **don't claim** any school is SFI-accredited; Cocopelli's recognition claim is attributed to Cocopelli.
